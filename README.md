# Landing Page de Carlos Eduardo Cupul Hau

Este es el repositorio del código fuente de mi landing page personal, diseñada para mostrar mi perfil profesional como desarrollador de software. La página está construida con HTML y CSS, y presenta un diseño moderno y responsivo que se adapta a cualquier dispositivo.

## Características

- **Diseño Profesional:** Una interfaz limpia y moderna que destaca mi experiencia y habilidades.
- **Totalmente Responsivo:** Perfectamente visible en dispositivos móviles y de escritorio.
- **Secciones Clave:**
  - **Sobre Mí:** Una breve introducción sobre mi pasión por el desarrollo de software.
  - **Experiencia Profesional:** Detalles sobre mis 5 años de experiencia con tecnologías como C# y ASP.NET.
  - **Áreas de Especialización:** Un listado de mis habilidades clave, incluyendo desarrollo backend, arquitectura de software y más.

## Cómo Empezar

Para ver el proyecto localmente, simplemente abre el archivo `index.html` en tu navegador web.

```bash
# Clona el repositorio
git clone https://github.com/tu_usuario/tu_repositorio.git

# Navega al directorio del proyecto
cd tu_repositorio

# Abre el archivo en tu navegador
# (Haz doble clic en index.html)
```
